# User Story: Catching up

**Status: stub.** Opening the app to unread messages and deciding what to deal with.

## Must cover

- Where the user lands with several strands unread, and how they triage.

- Marking something unread again to deal with later.
- Date separators, grouping consecutive messages from one sender, and returning to where the user left off.
