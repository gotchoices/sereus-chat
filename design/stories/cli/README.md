# serchat stories

`serchat` is a command-line chat client for testing, evaluating and debugging Sereus
Chat — not the way most people will chat. These stories are deliberately few and
short; each is an example session. The command reference is
[`design/specs/cli/commands.md`](../../specs/cli/commands.md).
